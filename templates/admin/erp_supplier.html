PaintIt - automatic shipment updates / 自动回传物流信息

PaintIt reads your shipments through the WooCommerce store "PaintIt" in MangoERP.
PaintIt 通过芒果店长中的 WooCommerce 店铺「PaintIt」读取发货信息。

0. Carrier for WooCommerce (fixes "对应的平台承运商没有设置") / WooCommerce 承运商
   物流设置 → 物流渠道 → open the channel used (云途物流 / YunExpress) → 承运商 table:
   on the line "woocommerce" there is no 编辑 button, only the field 自定义承运商 (custom carrier).
   Type exactly: YunExpress   then save.
   在「物流设置 → 物流渠道」中打开所用渠道（云途物流）→「承运商」表格：「woocommerce」这一行没有「编辑」按钮，
   只有「自定义承运商」输入框，请填写：YunExpress，然后保存。
   Then re-submit the failed orders / 然后重新提交「提交失败」的订单。

1. Tracking number / 运单号
   After the parcel label is created (分配运单号), the order must be SUBMITTED to the store:
   订单 → 提交平台 (Submit to platform / 标记发货).
   This sends the carrier + tracking number (e.g. YunExpress YT...) to PaintIt.
   生成运单号后，请在订单中点击「提交平台」（标记发货），系统会把物流商和运单号（例如云途 YT...）回传给 PaintIt。

2. Make it automatic / 设置自动提交
   In MangoERP order rules (订单规则 / 自动化规则), enable
   "automatically submit to platform after the tracking number is assigned" for the store PaintIt.
   请在「订单规则」中为 PaintIt 店铺开启「分配运单号后自动提交平台（自动标记发货）」。

3. Use the tracking number the customer can follow (YunExpress YT..., not an internal number).
   请回传客户可以查询的运单号（云途 YT...），不要回传内部单号。

4. Check / 确认
   Within 15 minutes the order shows "Shipped" in PaintIt. If not, tell us the order number.
   提交后 15 分钟内 PaintIt 订单会变为「已发货」。如果没有，请告诉我们订单号。
