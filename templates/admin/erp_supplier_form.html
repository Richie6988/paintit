Shopify (relais ERP)

Si le fournisseur travaille via Shopify (ex. Yingsa Art avec MangoERP) : PaintIt reste votre site et encaisse avec Stripe, et chaque commande payée est recréée automatiquement dans votre boutique Shopify, où son ERP la récupère. Son expédition revient ici automatiquement (suivi + e-mail client).

Choisissez « Shopify » dans Intégration ci-dessus.

{% if sup.shopify.client_secret %}{% endif %}
{% if sup.shopify.static_token %}{% endif %}
Shopify → Paramètres → Applications → Développer des apps (Dev Dashboard) → créer une app installée sur votre boutique avec les accès write_orders, read_orders, write_products, read_products, read_fulfillments, read_merchant_managed_fulfillment_orders, puis copier Client ID / Client secret. Le jeton (24 h) est renouvelé automatiquement.
